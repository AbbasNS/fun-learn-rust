# Rust Tip of the Day

A daily Rust tip series for developers coming from other languages (Java, Python, C++, JS/TS, C#, Go, Kotlin). Some tips have a follow-up discussion with reader questions and answers.

[Read the numbered mdBook](https://abbasns.github.io/fun-learn-rust/) or browse the canonical [source table of contents](tips/SUMMARY.md).

To preview the book locally, install mdBook and run `mdbook serve --open` from the repository root.
